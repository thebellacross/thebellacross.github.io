# Exhibition assets

The homepage and galleries use the supplied local photographs in `images/music-production/`,
`images/dj-performance/`, and `images/music-curation/`. Original filenames are preserved.
Web copies are orientation-corrected and metadata-stripped, at a maximum of 2400 pixels.
Original uploads remain in the supplied ZIP files.

The `studies/` folder contains unused procedural artwork from the initial prototype.
These files are retained for reference and are not shown as BELLACROSS work.
